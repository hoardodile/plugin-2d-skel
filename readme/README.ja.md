# 2Dスケル

hoardodile のコンテンツプラグインです。Live2D・Spine・DragonBones のアニメーションビューアーで、1 つのビューアーで単一リソースから 3 形式のアニメーションキャラクターをレンダリングします。

- **Live2D** — 公式 Cubism `*.model3.json` モデルと Live2DViewerEX 設定（`model0.json` + `.moc3`/`.moc`、マルチバリアント）：モーショングループ、表情、EX 会話/選択メニュー、サウンド、当たり判定、モデルバリアント。
- **Spine** — 直接 `.json`/`.skel` + `.atlas` 出力と Live2DViewerEX `type: 9` 設定（`model0.json` + `skeleton_N` + `atlases_*`）：アニメーション/スキン/オーバーレイ選択、EX 当たり判定、会話、サウンド、モデルバリアント。
- **DragonBones** — 直接 `*_ske.json`/`*_dbbin` + `*_tex.json` アトラス出力と Live2DViewerEX `type: 10` 設定：アニメーション、アーマチュア、スキン選択とモデルバリアント。

ビューアーは各シーンの `engine` に応じて型安全なアダプターで振り分けます。共有シェル（シーンセレクター、再生操作、会話、ステータス）は 1 回だけ記述し、エンジン固有の操作は各エンジンのコンポーネントの背後に置きます。

## 機能

- Cubism + Live2DViewerEX、Spine（直接 + EX）、DragonBones（直接 + EX）の検出。各エンジンのモーショングループ、表情、EX 会話/選択メニュー、サウンド、当たり判定、モデルバリアント。
- 透明/チェッカー背景、ループ、インタラクト、スクリーンショット、全画面。
- 専有の Live2D ランタイムは**同梱されません**。初回の Live2D モデル表示時にユーザーの同意を得た一括ダウンロードで取得します（sha256 固定、プラグイン専用の vault に保存）。Spine と DragonBones は同梱ランタイムを使用します。
- ライブラリの検索フィルターでモデル種別（Cubism / 標準 / EX / 龙骨）ごとに絞り込めます。

## 要件

- hoardodile ≥ 0.1.8（詳しくはリポジトリの README を参照）。
- インストール前にリポジトリを信頼してください。プラグインコードは制限付きサンドボックス内でサーバー側として実行されます。
